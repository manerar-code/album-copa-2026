# ADR-005: Onboarding Layout Fix — StyleSheet Padding Adjustment

**Date:** 2026-06-03
**Status:** Accepted

## Decision

Fix onboarding overlaps and truncation by adjusting `paddingTop`, `marginBottom`, and content area `paddingBottom` values in the existing StyleSheet of `OnboardingModal.tsx`. No structural refactor with SafeAreaView.

## Alternatives Considered

- **SafeAreaView/useSafeAreaInsets refactor:** More robust across iPhone models but requires structural changes to the component and increases risk of regression.

## Consequences

- Minimal diff — only StyleSheet values change.
- Lower regression risk.
- May need revisiting if future iPhone models have unusual notch dimensions, but acceptable for current scope.
