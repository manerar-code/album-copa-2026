# ADR-003: CromoCard Owned State — Plain View with Green Border

**Date:** 2026-06-03
**Status:** Accepted

## Decision

The owned sticker state uses a plain `View` with `borderColor: colors.owned.border` (green) and `borderWidth: 2.5`. The `LinearGradient` wrapper is removed from the owned state and reserved exclusively for the duplicate state.

## Alternatives Considered

- **Green LinearGradient:** Replaces gold gradient with green tones. More visually similar to duplicate state, risks visual confusion between the two states.

## Consequences

- Owned and duplicate states are visually unambiguous: green solid border vs gold gradient border.
- CromoCard render logic is simpler — no gradient for owned.
- Check icon removal is straightforward since the owned branch is a plain View.
