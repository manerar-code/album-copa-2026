# ADR-001: Trocas Redesign — Unified Inline Comparison with Live CromoCard Result

**Date:** 2026-06-16
**Status:** Accepted

## Context

The Trocas screen uses a two-view state machine (`'input' | 'result'`). The user must: (1) paste text, (2) press "Comparar", (3) view a result list of plain sticker numbers grouped by country, (4) press "Nova comparação" to restart. This flow has four friction points and displays results as plain text, visually inconsistent with the Repetidas screen which uses CromoCard grids.

Three redesign approaches were evaluated.

## Decision

Implement a single scrollable screen: a multiline TextInput at the top, with a CromoCard result grid appearing directly below after a ~400 ms debounce whenever valid sticker codes are detected in the input. No "Comparar" button and no view navigation. The result section is visually identical to the Repetidas screen (flag, country header, CromoCard grid). The existing `ViewState` machine is removed.

## Alternatives Considered

- **Approach 2 — Auto-transition two-views:** Keep the `'input' | 'result'` state machine but trigger `handleComparar` automatically via `useEffect` instead of on button press. Result still replaces the input view; user needs an "Editar lista" button to go back. Less refactoring required, but users lose visual connection between input and result and editing the list requires extra navigation.
- **Approach 3 — Split-screen:** Fixed TextInput top half, SectionList bottom half, always visible. Good for wide screens (tablet/web) but poor on small phones where the input area competes for space with the result list.

## Consequences

- The `ViewState` state machine and `handleComparar` function are removed; comparison is reactive to input changes.
- All 14 existing `TradesScreen` integration tests that target the two-view flow must be rewritten.
- `ScrollView` + multiline `TextInput` keyboard-handling on mobile requires `keyboardShouldPersistTaps="handled"` and tested scroll behavior.
- Visual consistency with Repetidas is gained: CromoCard grids, same section headers, same share button style.
