# ADR-002: Cross-Album Duplicate Detection — Store Selector

**Date:** 2026-06-02
**Status:** Accepted

## Context

BUG-07 requires detecting stickers that are marked as "duplicate" in another user album and highlighting them in the current album view. A location for this computation must be chosen.

## Decision

Add a `getCrossAlbumDuplicates(figurinhaId)` selector to the existing `stickerStore.ts`. It reads `allCollections` (already in memory) and returns the list of album IDs where the sticker is marked as duplicate.

## Alternatives Considered

- **Dedicated hook (`useCrossAlbumDuplicates`):** Adds a new file and abstraction layer not strictly necessary.
- **Inline useMemo in each screen:** Duplicates logic across screens; harder to maintain.

## Consequences

- No new files required.
- Logic is co-located with `allCollections` and `toggleSticker`, which already own cross-album state.
- All screens that need cross-album data call the same selector.
