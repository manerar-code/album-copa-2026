# ADR-003: Cross-Album Confirmation Dialog — Alert.alert

**Date:** 2026-06-02
**Status:** Accepted

## Context

When a user marks a sticker as "owned" in Album B that is "duplicate" in Album A, the app must ask if the user wants to update Album A. A dialog mechanism must be chosen.

## Decision

Use React Native's built-in `Alert.alert()` for the confirmation dialog.

## Alternatives Considered

- **Custom modal:** Requires new component, layout work, and style matching. Adds complexity without meaningful UX gain for a single confirmation.
- **Bottom sheet:** No existing bottom sheet pattern in the app; would require new infrastructure.

## Consequences

- Consistent with existing confirmation pattern (`confirm()` helper already used in `UserAlbumsModal.tsx`).
- No new component needed.
- Native look on iOS; acceptable trade-off vs. custom branded dialog.
