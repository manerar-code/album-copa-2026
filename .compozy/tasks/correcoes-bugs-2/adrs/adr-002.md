# ADR-002: Sticker "Tenho" State — Green Border, No Check Icon

**Date:** 2026-06-03
**Status:** Accepted

## Decision

The "owned" sticker state uses a green border only. The check icon in the top-left corner is removed entirely. No replacement indicator is added.

## Alternatives Considered

- **Replace with dot indicator:** Adds visual noise without meaningful information gain.

## Consequences

- Consistent with market standard (owned = green, duplicate = yellow/gold).
- Simpler CromoCard render logic — no conditional icon overlay for owned state.
