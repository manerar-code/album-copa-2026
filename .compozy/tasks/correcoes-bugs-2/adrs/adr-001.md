# ADR-001: Bug Fix Delivery Strategy — Categorical with Single Build

**Date:** 2026-06-03
**Status:** Accepted

## Context

12 UI bugs were identified across visual sticker states, type labels, layout overlaps, and onboarding screens. A delivery strategy was needed.

## Decision

All 12 bugs are corrected in a single development cycle organized into 4 categories: sticker visual, labels/types, layout/overlap, and onboarding. One EAS build is submitted at the end.

## Alternatives Considered

- **Big Bang linear:** Simpler to describe but no prioritization if issues arise mid-cycle.

## Consequences

- Clear execution order within each category reduces merge conflicts.
- Single build means all fixes must pass web regression before triggering EAS.
